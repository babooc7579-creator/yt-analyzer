# 타임머신 CRM - 유튜브 소재 발굴 도구

타임머신 CRM은 유튜브 채널과 영상 데이터를 모니터링하고, 과거에 크게 반응이 있었던 영상을 다시 발굴해 새로운 콘텐츠 아이디어로 전환하는 개인용 크리에이터 도구입니다.

핵심 컨셉은 **또터또**, 즉 “터진 건 또 터진다”입니다. 6개월 이상 지난 영상 중에서도 여전히 리메이크 가치가 있는 소재를 찾아내고, 한국어 제목/쇼츠 대본/콘텐츠 기획으로 이어가는 것을 목표로 합니다.

---

## 현재 프로젝트 상태

이 저장소는 React + Vite 기반의 프론트엔드 앱입니다. 현재 코드에는 다음 기능들이 포함되어 있습니다.

- 유튜브 채널 등록
- 채널 미리보기
- 여러 채널 일괄 추가
- 카테고리/태그/언어 관리
- Azure Function API 연동
- 클라우드 채널 목록 불러오기
- 채널별 영상 데이터 조회
- 쇼츠/롱폼 필터
- 조회수, 평균 대비 성과, 일 조회수, 좋아요 비율 기준 정렬
- 6개월 이상 지난 영상 기반의 또터또 발굴 흐름
- 댓글 Top 10 조회
- 스크랩북 저장
- AI 리메이크 프롬프트 복사

자세한 앱 설계 방향은 아래 문서를 참고합니다.

```txt
docs/APP_BLUEPRINT.md
```

## 로컬에서 실행하기

먼저 저장소를 로컬 PC에 복제합니다.

```bash
git clone https://github.com/babooc7579-creator/yt-analyzer.git
cd yt-analyzer
```

의존성을 설치합니다.

```bash
npm install
```

개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에 표시되는 로컬 주소로 접속합니다. 보통 아래와 같은 주소가 표시됩니다.

```txt
http://localhost:5173
```

---

## 빌드하기

배포용 파일을 생성하려면 아래 명령어를 실행합니다.

```bash
npm run build
```

빌드 결과물은 `dist` 폴더에 생성됩니다.

---

## 미리보기 실행

빌드된 결과물을 로컬에서 미리 확인하려면 아래 명령어를 사용합니다.

```bash
npm run preview
```

## Azure Static Web Apps 배포 설정

Azure Portal에서 Static Web App을 만들 때 기본 설정은 다음과 같습니다.

- 빌드 프리셋: `Vite`
- 앱 위치: `/`
- 출력 위치: `dist`
- API 위치: 별도 Azure Function App 사용 시 비워둘 수 있음

현재 프론트엔드는 Azure Function API Base URL을 통해 백엔드와 통신합니다.

## 사용 흐름

1. 앱에 접속합니다.
2. YouTube Data API Key를 입력합니다.
3. 관심 있는 유튜브 채널을 등록합니다.
4. 채널에 태그와 언어를 지정합니다.
5. 채널을 스캔해 영상 데이터를 수집합니다.
6. 조회수, 성과 배수, 일 조회수, 좋아요 비율 기준으로 영상을 정렬합니다.
7. 6개월 이상 지난 영상 중 리메이크 가치가 높은 영상을 찾습니다.
8. 마음에 드는 영상을 스크랩합니다.
9. 선택한 영상들을 기반으로 AI 리메이크 프롬프트를 복사합니다.
10. ChatGPT에서 제목, 대본, 기획안으로 확장합니다.

## 앱의 장기 방향

타임머신 CRM은 단순한 영상 조회기가 아니라, 크리에이터가 매일 쓸 수 있는 **소재 발굴 OS**를 목표로 합니다.

앞으로의 방향은 다음과 같습니다.

- 대시보드 신설
- 채널 관리 화면 분리
- 영상 발굴 화면 고도화
- 또터또 점수화
- 스크랩북/아이디어 보관함 강화
- 리메이크 상태 관리
- AI 프롬프트 템플릿 고도화
- 제작 완료/업로드 후보 관리

## 개발 원칙

- 기존 기능을 한 번에 갈아엎지 않고, 작은 단위로 안전하게 개선합니다.
- 사용자가 개발자가 아니어도 이해할 수 있는 UI 문구를 우선합니다.
- API Key 같은 민감한 값은 저장소에 커밋하지 않습니다.
- 기능을 추가하기 전에 문서와 설계를 먼저 정리합니다.
- 앱의 중심은 데이터가 아니라 “좋은 콘텐츠 소재를 찾는 과정”입니다.
