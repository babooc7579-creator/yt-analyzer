# 타임머신 CRM - 유튜브 소재 발굴 도구

타임머신 CRM은 유튜브 채널과 영상 데이터를 모니터링하고, 과거에 크게 반응이 있었던 영상을 다시 발굴해 새로운 콘텐츠 아이디어로 전환하는 개인용 크리에이터 도구입니다.

핵심 컨셉은 **또터또**, 즉 “터진 건 또 터진다”입니다. 6개월 이상 지난 영상 중에서도 여전히 리메이크 가치가 있는 소재를 찾아내고, 한국어 제목/쇼츠 대본/콘텐츠 기획으로 이어가는 것을 목표로 합니다.

---

## 현재 프로젝트 상태

이 저장소는 React + Vite 기반의 프론트엔드 앱입니다. 현재 코드에는 다음 기능들이 포함되어 있습니다.

- 유튜브 채널 등록
- 채널 미리보기
- 여러 채널 일괄 추가
- 카테고리/태그/언어/채널 등급/운영 상태 관리
- Azure Function API 연동
- 클라우드 채널 목록 불러오기
- 채널별 저장 영상 데이터 조회
- 저장 영상 기반 오늘의 레이더
- 등급과 마지막 수집일 기준의 오늘 볼 채널 화면
- 저장 영상 제목과 채널명을 찾는 키워드 탐색
- 기존 채널 태그별 저장 영상을 묶어 보는 태그별 금고
- 쇼츠/롱폼 필터
- 조회수, 평균 대비 성과, 일 조회수, 좋아요 비율 기준 정렬
- 6개월 이상·평균 대비 1.5배 이상 저장 영상을 모은 터또터 전용 탐색 화면
- 댓글 Top 10 조회
- Cloud 우선 스크랩북 저장
- 수동 발견 링크 저장
- 발견 링크 제작 후보 연결
- 제작 후보함의 영상 후보/발견 링크 후보 확인
- 제작 후보함 검색·진행 단계 필터와 제작 작업 묶음 복사
- 제작 후보 카드의 작업 준비 체크와 우선 확인 안내
- 제작 후보의 목표 업로드 날짜를 확인하는 업로드 캘린더
- 업로드 캘린더 일정에서 해당 항목을 제작 후보함 검색으로 바로 여는 연결
- 제작 후보함의 다음 행동에서 업로드 캘린더로 이동하는 연결
- 홈에서 키워드 탐색·태그별 금고·업로드 캘린더로 바로 이동하는 실사용 도구 바로가기
- 영상/링크 URL 복사
- AI 리메이크 프롬프트 복사
- 주요 화면 흐름과 문구를 보호하는 테스트

자세한 앱 설계 방향은 아래 문서를 참고합니다.

## 로컬에서 실행하기

먼저 저장소를 로컬 PC에 복제합니다.

```bash
git clone https://github.com/babooc7579-creator/yt-analyzer.git
cd yt-analyzer
```

의존성을 설치합니다.

```bash
npm install
```

개발 서버를 실행합니다.

```bash
npm run dev
```

브라우저에 표시되는 로컬 주소로 접속합니다. 보통 아래와 같은 주소가 표시됩니다.

```txt
http://localhost:5173
```

## 빌드하기

배포용 파일을 생성하려면 아래 명령어를 실행합니다.

```bash
npm run build
```

빌드 결과물은 `dist` 폴더에 생성됩니다.

## Azure Static Web Apps 배포 설정

Azure Portal에서 Static Web App을 만들 때 기본 설정은 다음과 같습니다.

- 빌드 프리셋: `Vite`
- 앱 위치: `/`

현재 프론트엔드는 Azure Function API Base URL을 통해 백엔드와 통신합니다.

## 사용 흐름

1. 앱에 접속합니다.
2. 관심 있는 유튜브 채널을 등록하고 태그와 언어를 지정합니다.
3. 새 데이터가 필요할 때만 선택 채널 또는 태그 기준으로 새 영상 수집을 실행합니다.
4. 저장된 영상 불러오기로 Cloud DB에 이미 저장된 영상만 조회합니다.
5. 오늘의 레이더, 터또터 탐색, 키워드 탐색, 태그별 금고에서 후보 영상을 고릅니다.
6. 마음에 드는 영상을 Cloud 스크랩북이나 제작 후보로 보내고, 제작 후보함에서 업로드 캘린더를 열어 목표 날짜를 확인합니다.
7. 외부에서 본 링크는 발견함에 수동으로 저장합니다.
8. 제작 후보함에서 제목·메모·일정을 정리하고, 달력 일정의 `후보함에서 찾기`로 해당 후보를 다시 열거나 작업 묶음을 복사해 실제 제작으로 이어갑니다.
9. 영상/링크 URL 또는 AI 리메이크 프롬프트를 복사해 ChatGPT에서 제목, 대본, 기획안으로 확장합니다.

참고: YouTube Data API Key는 댓글 Top 10 조회처럼 프론트에서 YouTube API를 직접 호출하는 기능에 필요합니다. 저장된 영상 불러오기는 Cloud DB 조회이며, 새 YouTube API 호출이 아닙니다.

## 앱의 장기 방향

타임머신 CRM은 단순한 영상 조회기가 아니라, 크리에이터가 매일 쓸 수 있는 **소재 발굴 OS**를 목표로 합니다.

앞으로의 방향은 다음과 같습니다.

- 홈/오늘 레이더의 후보 판단 흐름 고도화
- 저장 영상 필터와 또터또 판단 신호 개선
- 스크랩북/참고 보관함/발견함/제작 후보함 사이의 작업 흐름 강화
- 발견 링크와 로컬 파일 연결 모델 검토
- 별도 제작 프로젝트 또는 제작 칸반 확장 검토
- AI 프롬프트 템플릿 고도화
- 제작 완료/업로드 후보 관리

주의: 별도 제작 DB, local assets, 새 endpoint, DB schema 변경, YouTube API 호출량 증가 작업은 선택지와 위험을 먼저 검토한 뒤 진행합니다.

## 개발 원칙

- 기존 기능을 한 번에 갈아엎지 않고, 작은 단위로 안전하게 개선합니다.
- 사용자가 개발자가 아니어도 이해할 수 있는 UI 문구를 우선합니다.
- API Key 같은 민감한 값은 저장소에 커밋하지 않습니다.
- 기능을 추가하기 전에 문서와 설계를 먼저 정리합니다.
- 앱의 중심은 데이터가 아니라 “좋은 콘텐츠 소재를 찾는 과정”입니다.

## 관련 문서와 주요 파일

- `docs/APP_BLUEPRINT.md` : 앱 전체 설계도
- `README.md` : 프로젝트 소개와 실행 방법
- `package.json` : 실행 스크립트와 의존성
- `src/App.jsx` : 현재는 레이아웃과 라우트를 연결하는 얇은 파일
- `src/hooks` : 채널, 영상, 발견함, 스크랩북, 제작 후보 흐름
- `src/services` : Cloud Function API, YouTube API, localStorage 보조 접근
- `src/utils` : 화면 props, 문구, 계산, 포맷팅
- `src/main.jsx` : React 앱 진입점
- `src/index.css` : TailwindCSS 진입점
