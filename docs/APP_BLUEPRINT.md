# 타임머신 CRM - 앱 설계도

> 이 문서는 `yt-analyzer` 앱의 초기 UI/UX 방향과 개발 우선순위를 정리한 설계 문서입니다.
> 목표는 단순한 유튜브 데이터 조회 도구가 아니라, **유튜브 소재를 발견하고, 비교하고, 저장하고, 리메이크 아이디어로 전환하는 개인용 크리에이터 OS**를 만드는 것입니다.

---

## 1. 앱의 핵심 목적

타임머신 CRM은 유튜브 채널과 영상을 관리하면서, 과거에 터졌던 영상 소재를 다시 발굴하는 도구입니다.

핵심 컨셉은 다음과 같습니다.

- **모니터링**: 관심 있는 유튜브 채널을 언어/카테고리/태그별로 저장합니다.
- **수집**: 채널의 영상 데이터를 주기적으로 모읍니다.
- **발굴**: 조회수, 평균 대비 성과, 업로드 기간, 좋아요 비율 등을 기준으로 좋은 소재를 찾습니다.
- **해석**: 왜 터졌는지 후킹 포인트를 분석합니다.
- **전환**: 한국어 콘텐츠 제목, 쇼츠 대본, 리메이크 아이디어로 바꿉니다.
- **보관**: 좋은 영상과 아이디어를 스크랩북에 저장합니다.

---

## 2. 사용자의 기본 흐름

1. API Key 또는 연결 상태 확인
2. 관심 채널 등록
3. 채널을 카테고리/태그/언어로 분류
4. 채널 스캔 실행
5. 영상 데이터 확인
6. 필터와 정렬로 후보 영상 찾기
7. 또터또 모드로 오래된 떡상 영상 발굴
8. 마음에 드는 영상을 체크 또는 스크랩
9. AI 리메이크 프롬프트 복사
10. ChatGPT에서 제목/대본/구성으로 확장

## 3. 권장 화면 구조

초기 UI는 복잡한 기능을 한 화면에 몰아넣기보다, 사용자의 사고 흐름에 맞춰 나누는 것이 좋습니다.

```txt
좌측 사이드바
├─ 대시보드
├─ 채널 관리
├─ 영상 발굴
├─ 또터또 모드
├─ 스크랩북
└─ 설정

상단 헤더
├─ 현재 선택된 작업명
├─ 스캔 상태
├─ API / Cloud 연결 상태
└─ 빠른 실행 버튼

메인 영역
└─ 현재 메뉴별 핵심 작업 화면
```

## 4. 메뉴별 설계

### 4.1 대시보드

대시보드는 현재 앱의 상태를 한눈에 보여주는 첫 화면입니다.

필수 카드:

- 등록 채널 수
- 수집된 영상 수
- 오늘/최근 스캔 상태
- 또터또 후보 수
- 최근 스크랩 영상 수
- 언어별/태그별 채널 분포

대시보드의 목적은 사용자가 앱에 들어오자마자 “오늘 무엇을 보면 되는지” 알게 하는 것입니다.

### 4.2 채널 관리

필수 기능:

- 단일 채널 추가
- 여러 채널 일괄 추가
- 채널 미리보기
- 태그 복수 선택
- 언어 선택
- 채널 메모 작성
- 채널 삭제
- 태그명 일괄 변경
- 태그별 채널 목록 보기

UX 원칙:

- 채널 추가는 “입력 → 미리보기 → 태그 선택 → 저장” 순서로 명확히 나눕니다.
- 일괄 추가는 별도 탭으로 분리해 실수를 줄입니다.
- 채널 카드는 구독자 수, 평균 조회수, 최근 스캔일, 등록 태그가 한눈에 보여야 합니다.

### 4.3 영상 발굴

필수 필터:

- 키워드 검색
- 조회수 기준
- 쇼츠/롱폼 구분
- 언어
- 태그
- 업로드 기간
- 정렬 기준: 조회수, 평균 대비 배수, 일 조회수, 좋아요 비율, 최신순

영상 카드에 보여야 할 정보:

- 썸네일
- 제목
- 채널명
- 업로드일
- 조회수
- 좋아요 비율
- 평균 대비 성과 배수
- 쇼츠/롱폼 표시
- 스크랩 버튼
- 댓글 분석 버튼
- AI 프롬프트용 체크박스

### 4.4 또터또 모드

또터또 모드는 “터진 건 또 터진다”라는 앱의 핵심 철학을 담는 화면입니다.

기준:

- 업로드 후 6개월 이상 지난 영상
- 해당 채널 평균 대비 높은 성과
- 현재 한국어 콘텐츠로 리메이크 가능한 소재
- 댓글 반응이 강한 영상
- 제목 구조가 재활용 가능한 영상

화면 설계:

- 상단에 또터또 설명 카드 배치
- 후보 영상을 점수순으로 정렬
- “왜 다시 쓸 수 있는가?”를 메모할 수 있는 공간 제공
- 여러 영상을 선택해 AI 리메이크 프롬프트 생성

### 4.5 스크랩북

스크랩북은 좋은 소재를 버리지 않고 쌓아두는 공간입니다.

필수 기능:

- 스크랩한 영상 목록
- 태그별 분류
- 메모 추가
- 리메이크 상태 표시: 미검토, 분석 완료, 대본화 완료, 제작 완료
- AI 프롬프트 복사
- 원본 영상 바로가기

### 4.6 설정

설정 화면에는 사용자가 헷갈릴 수 있는 기술 요소를 모읍니다.

필수 항목:

- YouTube Data API Key 입력/저장 방식 안내
- Azure Function API Base URL 확인
- CORS 오류 안내
- 로컬 실행 안내
- 배포 상태 확인
- 데이터 저장 위치 안내

## 5. UI 톤앤매너

앱은 전문가용 분석 도구이지만, 사용자는 개발자가 아닐 수 있습니다. 따라서 UI는 다음 원칙을 따릅니다.

- 어려운 개발 용어보다 작업 중심 문구를 사용합니다.
- 버튼 이름은 명확하게 씁니다.
- “분석”, “스캔”, “발굴”, “스크랩”, “리메이크” 같은 행동 단어를 중심으로 구성합니다.
- 숫자는 한국식 축약 표기를 사용합니다. 예: 25000 → 2.5만
- 오류 메시지는 원인과 다음 행동을 함께 안내합니다.

## 7. 좋은 첫 화면의 기준

앱을 켰을 때 사용자가 바로 이해해야 할 질문은 다음 3가지입니다.

1. 지금 내가 등록한 채널은 몇 개인가?
2. 오늘 새로 볼 만한 영상은 무엇인가?
3. 리메이크할 만한 또터또 후보는 무엇인가?

첫 화면은 이 3가지 질문에 답해야 합니다.

## 8. 개발 시 주의사항

- 기존 기능을 한 번에 갈아엎지 않습니다.
- 먼저 문서화하고, 그다음 화면을 나눕니다.
- API 연동부와 UI 표시부를 분리합니다.
- 저장소에 민감한 API Key를 커밋하지 않습니다.
- 사용자가 직접 실행하기 쉽도록 README를 계속 갱신합니다.

## 9. 현재 코드에서 확인된 주요 특징

현재 앱은 이미 다음 기능을 포함하고 있습니다.

- React/Vite 기반 프론트엔드
- TailwindCSS 스타일 구조
- Azure Function API 연동
- 채널 목록 클라우드 로딩
- 채널 단일/일괄 추가
- 태그/언어 관리
- 채널 스캔 요청
- 수집된 영상 조회
- 쇼츠/롱폼 필터
- 조회수/성과배수/일조회수/좋아요 비율 정렬
- 댓글 Top 10 조회
- 스크랩북 로컬 저장
- AI 리메이크 프롬프트 복사

따라서 앞으로의 방향은 “처음부터 다시 만들기”가 아니라, **현재 기능을 잘 보존하면서 구조와 사용성을 정리하는 것**입니다.
