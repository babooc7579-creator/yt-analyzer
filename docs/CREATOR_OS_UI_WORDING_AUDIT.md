# Creator OS UI 문구 감사

작성일: 2026-07-02

이 문서는 현재 화면 문구가 실제 동작과 맞는지 확인한 감사 문서입니다.

중요: 이 문서는 분석 문서입니다. 코드, API, DB schema, localStorage key는 변경하지 않습니다.

---

## 1. 감사 목적

사용자가 버튼을 누르기 전에 아래 내용을 알 수 있게 하는 것이 목적입니다.

- 저장된 DB를 조회하는 작업인지
- YouTube API를 호출하는 작업인지
- Cloud DB를 변경하는 작업인지
- localStorage 화면 설정만 바꾸는 작업인지
- 아직 준비중인 기능인지

## 3. 수정 후보

### 3.1 채널 저장 후 성공 메시지

현재 문구:

```txt
채널이 클라우드에 성공적으로 추가되었습니다! (최초 분석 시 영상 최대 250개를 수집합니다)
```

근거 파일:

- `src/App.jsx`

실제 백엔드 확인:

- `POST /channels`는 `fetchChannelInfo(handle)`로 채널 정보를 확인한 뒤 `channels` container에 저장합니다.
- 이 흐름에서 영상 250개를 바로 수집하지 않습니다.
- 영상 수집은 `POST /scan/selected`, `GET /scan`, `GET /scan?tag=...`의 scan 흐름에서 발생합니다.

문제:

- 사용자는 채널 저장만 했는데 영상도 같이 수집된다고 오해할 수 있습니다.
- 같은 화면의 다른 문구인 `영상 수집은 스캔 시 진행됩니다`와 충돌합니다.

추천 문구:

```txt
채널이 클라우드 목록에 추가되었습니다. 새 영상은 스캔 버튼을 눌렀을 때 수집됩니다.
```

위험도:

- 낮음.

사용자 판단 필요 여부:

- 필요 없음. 실제 동작을 더 정확히 설명하는 문구 수정입니다.

- 삭제 아이콘에 별도 설명이 부족합니다.

추천 문구:

```

```

위험도:

- 낮음.

사용자 판단 필요 여부:

- 필요 없음. 실제 동작 설명을 정확히 하는 문구 수정입니다.

## 6. 2026-07-03 추가 적용 기록

아래 작업은 기능 흐름, API 호출, DB 저장 구조를 바꾸지 않고 화면 요소의 설명만 보강한 작업입니다.

적용된 범위:

1. 주요 버튼 `title` / `aria-label` 보강
   - 채널 추가/삭제/태그 관리
   - 레이더 후보 처리
   - 제작 칸반 이동/저장
   - 발견함 저장/수정/삭제
   - 스크랩북 및 프롬프트 복사

2. 입력/선택 컨트롤 설명 보강
   - 채널 핸들/링크 입력
   - 채널 언어 선택
   - 채널 등급/상태 선택
   - 발견 링크 URL/제목/메모/상태/권리 상태
   - 제작 칸반 제목/메모/업로드 예정일
   - 댓글 Top 10용 YouTube API Key

3. 새 탭 링크 설명 보강
   - 저장 영상 카드/리스트의 YouTube 원본 링크
   - 레이더 후보의 YouTube 원본 링크
   - 스크랩북과 제작 칸반의 YouTube 원본 링크

4. 발견함 피드백 안내 보강
   - 오류 메시지는 `alert`로 표시합니다.
   - 저장 중, 저장 완료, 불러오는 중 메시지는 상태 변경으로 안내합니다.

5. 발견함에서 제작 후보로 보내는 빠른 버튼 추가
   - 발견 링크 카드에 `제작 후보로` 버튼을 추가했습니다.
   - 이 버튼은 새 DB나 새 endpoint를 만들지 않고 기존 발견 링크의 `status`를 `candidate`로 저장합니다.
   - 이미 후보인 링크는 `후보 등록됨`으로 표시해 제작실에 보이는 상태임을 알 수 있게 했습니다.
   - 홈 화면의 `발견함 저장` 설명도 링크 저장 후 제작 후보로 보낼 수 있다는 흐름에 맞게 조정했습니다.
   - `rightsStatus: do_not_use` 상태에서 제작 후보로 보내려면 기존과 동일하게 확인 문구를 거칩니다.

6. 홈 화면 후보 흐름 버튼 추가
   - 홈 화면의 `오늘 작업 흐름` 중 `제작 후보로 넘기기` 카드에 `후보함`과 `발견함` 버튼을 추가했습니다.
   - `후보함`은 기존 제작 후보 화면으로 이동하고, `발견함`은 외부 링크 발견함 화면으로 이동합니다.
   - 후보가 0개여도 `후보함`은 열 수 있게 유지합니다. 비어 있는 제작 후보 화면에서 다음 행동 안내를 볼 수 있기 때문입니다.
   - 홈의 영상 후보 숫자는 제작 후보함 화면과 같은 기준인 스크랩/제작 후보 영상 기준으로 표시합니다.
   - 이 버튼은 화면 이동만 담당하며 새 endpoint, 새 DB, YouTube API 호출을 추가하지 않습니다.

7. 제작 후보함 기준 문구 정리
   - 제작 후보함 상단 문구를 `영상 n개 후보`가 아니라 `영상 n개 관리`로 조정했습니다.
   - 영상 기준은 스크랩북/제작 상태 기록, 링크 기준은 발견함에서 제작 후보로 표시한 링크라고 화면에 표시합니다.
   - 이 문구는 숫자 의미를 명확히 하기 위한 안내이며 새 endpoint, 새 DB, YouTube API 호출을 추가하지 않습니다.

8. 상단 헤더 숫자 문구 정리
   - 상단 헤더의 `영상 후보` 라벨을 `스크랩 영상`으로 바꿨습니다.
   - 상단 헤더의 `영상` 라벨을 `불러온 영상`으로 바꿨습니다.
   - 제작 후보함 설명은 `스크랩 영상과 발견함 링크를 제작 후보로 모아봅니다`로 조정했습니다.
   - 이는 실제 저장 기준을 더 명확히 보여주기 위한 문구 변경이며 데이터 흐름은 바꾸지 않습니다.

9. 제작 후보함/스크랩북 헤더 분리
   - 같은 스크랩북 기반 화면이라도 `제작 후보함`에서는 상단 제목을 `제작 후보함`으로 표시합니다.
   - `제작/스크랩북` 화면에서는 기존 `영구 보관 스크랩북` 제목을 유지합니다.
   - 화면 성격에 맞춘 문구 분기이며 스크랩 저장, 프롬프트 복사, 제작 상태 저장 로직은 바꾸지 않습니다.

10. 제작 후보 카드 상태 버튼 안내 추가
   - 제작 후보함의 영상 카드에 상태 버튼 안내 문구를 추가했습니다.
   - `제작 후보로`, `제작 중으로`, `업로드 완료` 버튼은 Cloud 판단 기록에 저장되며 YouTube API를 새로 호출하지 않는다고 표시합니다.
   - 저장 동작과 상태값은 바꾸지 않고, 사용자가 버튼 의미를 더 쉽게 이해하도록 돕는 문구 변경입니다.

11. 발견 링크 카드 상태 선택 안내 추가
   - 발견함 링크 카드에 검토 상태와 권리 상태 선택 안내 문구를 추가했습니다.
   - 상태와 권리 상태 표시는 바꾸는 즉시 Cloud 발견함에 저장되며, 외부 사이트를 새로 수집하지 않는다고 표시합니다.
   - 발견 링크 저장/수정/삭제 API와 DB 구조는 바꾸지 않고, 카드 안에서 상태 선택의 의미만 더 명확하게 했습니다.

12. 발견 링크 삭제 확인 문구 보강
   - 발견 링크 삭제 확인창과 삭제 버튼 설명에 `Cloud 발견함 기록만 삭제`된다고 명시했습니다.
   - 원본 사이트 게시물이나 외부 링크 자체는 삭제되지 않는다고 안내합니다.
   - 삭제 API 동작과 DB 구조는 바꾸지 않고, 사용자가 삭제 범위를 오해하지 않도록 확인 문구만 보강했습니다.

13. 제작 후보함 링크 후보 제외 버튼 설명 보강
   - 제작 후보함의 발견 링크 후보 카드에서 `후보 제외` 버튼 설명을 보강했습니다.
   - 이 버튼은 링크를 삭제하지 않고 발견함의 상태를 `후보 제외`로 저장한다고 명시합니다.
   - 발견 링크 status 저장 흐름은 유지하고, 삭제와 상태 변경을 혼동하지 않도록 문구만 정리했습니다.

14. 홈 발견함 바로가기 힌트 문구 정정
   - 홈 화면의 `발견함 저장` 바로가기 힌트를 `API 호출 없이 링크만 저장`에서 `외부 수집 없이 링크만 저장`으로 바꿨습니다.
   - 발견함은 Cloud 저장 API를 사용하므로, 넓은 의미의 API 호출이 전혀 없다는 표현은 피했습니다.
   - 의도는 YouTube API 호출, 외부 사이트 크롤링, 자동 다운로드 없이 링크 기록만 저장한다는 점을 명확히 하는 것입니다.

15. 홈 후보 처리 문구 정리
   - 홈 화면의 제작 후보 흐름 설명에서 `봄/나중/제외` 표현을 실제 처리 이름에 맞게 `봤음/나중에 보기/제외`로 바꿨습니다.
   - 레이더 후보 처리 버튼과 같은 용어를 사용해 사용자가 다음 행동을 더 쉽게 이해하도록 맞췄습니다.
   - 상태 저장 로직이나 후보 표시 기준은 바꾸지 않았습니다.

16. 채널 삭제 안내 보강
   - Cloud 채널 목록 삭제 확인창에 삭제 후 저장 영상 조회와 새 영상 수집 대상에서 빠진다고 명시했습니다.
   - 채널 목록 삭제 버튼의 `title`과 `aria-label`도 같은 의미로 보강했습니다.
   - 채널 삭제 API 동작은 바꾸지 않고, 사용자가 삭제의 영향 범위를 누르기 전에 이해하도록 문구만 정리했습니다.

17. 채널 등급/상태 선택 설명 보강
   - 채널 등급 선택은 중요도 표시이며 새 영상 수집 주기를 자동으로 바꾸지 않는다고 설명했습니다.
   - 채널 상태 선택은 활성 채널만 새 영상 수집 대상이고 변경 내용은 Cloud에 저장된다고 설명했습니다.
   - 채널 metadata 저장 로직은 바꾸지 않고, 등급과 상태가 각각 무엇을 의미하는지만 명확히 했습니다.

18. 발견 링크 삭제 피드백 문구 정리
   - 발견 링크 삭제 진행/완료/실패 메시지에서 `링크` 대신 `링크 기록`이라고 표현했습니다.
   - 원본 사이트 링크 자체가 사라지는 것이 아니라 Cloud 발견함의 저장 기록이 삭제된다는 의미에 맞췄습니다.
   - 삭제 API와 상태 갱신 로직은 바꾸지 않았습니다.

19. 저장 영상/오늘 레이더 제작 후보 버튼 설명 보강
   - 저장 영상 카드와 리스트의 `제작 후보로` 버튼 설명을 Cloud 판단 기록 저장 기준으로 맞췄습니다.
   - 오늘 레이더의 판단 버튼 설명에 Cloud 판단 기록 저장과 YouTube API 호출 없음 기준을 보강했습니다.
   - 제작 후보 저장, 봤음, 나중에 보기, 후보 제외 로직은 바꾸지 않고 버튼 의미와 저장 위치만 더 명확히 했습니다.

20. 발견함 상태 변경/새로고침 설명 보강
   - 발견 링크의 검토 상태, 권리 상태 표시, 제작 후보 등록 설명을 Cloud 발견함 기록 저장 기준으로 맞췄습니다.
   - 발견함 새로고침 버튼 설명에 Cloud 목록 재조회이며 외부 사이트를 새로 수집하지 않는다고 명시했습니다.
   - 발견 링크 저장/수정/조회 API와 DB 구조는 바꾸지 않고 사용자가 외부 수집과 Cloud 조회를 혼동하지 않도록 문구만 정리했습니다.

21. 새 영상 수집 버튼 설명 보강
   - 영상 도구막대의 새 영상 수집 버튼 설명에 YouTube API 호출과 저장 영상 불러오기와 다른 작업이라는 점을 보강했습니다.
   - 태그별 새 영상 수집 아이콘 버튼도 같은 기준으로 접근성 설명을 맞췄습니다.
   - 수집 로직, 대상 채널 계산, endpoint 호출은 바꾸지 않고 비용성 작업 안내만 더 명확히 했습니다.

22. 저장 영상/채널/스크랩북 URL 복사 버튼 추가
   - 저장 영상 카드와 리스트에 `URL 복사` 버튼을 추가해 YouTube 원본 링크를 바로 클립보드에 복사할 수 있게 했습니다.
   - 채널 목록에는 아이콘 버튼으로 `채널 URL 복사`를 추가했습니다.
   - 스크랩북과 제작 후보함의 영상 카드에도 `URL 복사` 버튼을 추가했습니다.
   - 스크랩북/제작 후보함 헤더에는 제목과 YouTube 원본 링크를 묶어 복사하는 `URL 목록 복사` 버튼을 추가했습니다.
   - 채널 목록에는 현재 카테고리에 보이는 채널명과 YouTube URL을 묶어 복사하는 `채널 URL 목록 복사` 버튼을 추가했습니다.
   - 발견함에는 현재 검색/필터 조건에 맞는 링크 제목, URL, 상태, 권리 상태를 묶어 복사하는 `URL 목록 복사` 버튼을 추가했습니다.
   - 저장 영상 보드에는 현재 검색/필터/정렬 조건으로 보이는 영상 제목과 YouTube URL을 묶어 복사하는 `영상 URL 목록 복사` 버튼을 추가했습니다.
   - 이 버튼은 브라우저 클립보드에 텍스트만 복사하며 YouTube API 호출, Cloud DB 저장, localStorage 변경을 하지 않습니다.
   - 원본 파일 자동 다운로드/업로드는 MVP에서 제외하고, URL 보존과 붙여넣기 편의를 우선한다는 결정에 맞춘 작은 UI 편의 기능입니다.

23. 발견 링크 권리 상태/제작 후보 문구 정리
   - `권리 확인`처럼 완료된 검증으로 오해될 수 있는 표현을 `권리 상태` 중심으로 정리했습니다.
   - `사용 금지` 링크를 제작 후보로 보내는 확인창과 안내문에 권리 확인 완료나 사용 허가를 의미하지 않는다고 명시했습니다.
   - 제작 후보함에서 발견 링크를 되돌리거나 제외할 때 Cloud 발견함 상태만 바뀌고 링크 기록은 유지된다고 표시했습니다.

24. 영상/채널 선택 라벨 단순화
   - 영상 조회수/길이 필터의 이모지 접두어를 제거하고 일반 텍스트로 정리했습니다.
   - 채널 언어, 통계, 미리보기 성공, 일괄 추가 실패 표시의 기호/이모지 표현을 일반 텍스트로 바꿨습니다.
   - 필터 값, 언어 코드, 채널 통계 계산, 저장/수집 로직은 바꾸지 않았습니다.
