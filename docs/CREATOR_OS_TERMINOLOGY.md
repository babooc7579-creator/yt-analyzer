# Creator OS 사용자 용어 기준

작성일: 2026-07-28

이 문서는 Creator OS 화면과 작업 보고에서 사용하는 용어를 사용자 관점으로 통일하기 위한 기준입니다.

## 1. 수집 영상 목록

Creator OS는 YouTube 영상 파일 자체를 다운로드하거나 보관하지 않습니다.

온라인 저장소(Azure DB)에 보관하는 것은 다음과 같은 영상 정보입니다.

- YouTube 영상 ID와 원본 링크
- 제목과 채널 정보
- 게시일
- 조회수와 좋아요 등의 통계
- 썸네일 주소
- 사용자의 판단, 메모, 제작 상태

따라서 화면에서는 다음 표현을 사용합니다.

- 메뉴: `수집 영상 목록`
- 버튼: `수집 영상 목록 불러오기`
- 설명: `온라인 저장소(Azure DB)에 보관된 수집 영상 정보를 조회합니다.`

`저장한 영상`, `저장 영상`, `영상 저장`처럼 실제 영상 파일을 보관하는 것으로 오해할 수 있는 표현은 사용하지 않습니다.

## 2. 온라인 저장소(Azure DB)

`Cloud 저장` 또는 `Cloud DB`를 단독으로 사용하지 않습니다.

사용자에게는 먼저 쉬운 의미를 말하고 실제 저장 위치를 괄호로 표시합니다.

- 조회: `온라인 저장소(Azure DB)에서 조회`
- 저장: `온라인 저장소(Azure DB)에 저장`
- 수정: `온라인 저장소(Azure DB)의 기록 변경`
- 삭제: `온라인 저장소(Azure DB)의 기록 삭제`

현재 장기 기준 데이터는 Azure Cosmos DB에 보관되고, 화면은 Azure Functions API를 통해 조회하거나 변경합니다.

## 3. 브라우저 임시 상태

현재 브라우저에서만 유지되는 선택과 임시 기록은 온라인 저장과 구분합니다.

- `현재 브라우저에만 임시 유지`
- `새로고침하면 초기화`
- `온라인 저장소(Azure DB)에는 저장하지 않음`

localStorage라는 기술 용어가 꼭 필요하면 `현재 브라우저의 임시 저장소(localStorage)`로 설명합니다.

## 4. YouTube 수집

YouTube에서 새 영상 정보를 확인하는 작업은 온라인 저장소 조회와 구분합니다.

- `YouTube에서 새 영상 정보 수집`
- `YouTube API 호출 가능`
- `수집된 새 영상 정보는 온라인 저장소(Azure DB)에 반영`

`수집 영상 목록 불러오기`는 이미 보관된 정보를 조회하는 작업이며 YouTube API를 호출하지 않습니다.

## 5. 버튼 설명 기준

중요한 버튼은 누르기 전에 다음 네 가지를 알 수 있어야 합니다.

1. 무엇을 하는지
2. 어디에서 조회하거나 저장하는지
3. 기존 데이터가 변경되는지
4. YouTube API 호출 가능성이 있는지

예시:

> 수집 영상 목록 불러오기
> 온라인 저장소(Azure DB)에 보관된 YouTube 영상 정보를 조회합니다. 영상 파일을 다운로드하지 않으며 YouTube API도 호출하지 않습니다.
